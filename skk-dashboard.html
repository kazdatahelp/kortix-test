Методология и примечания

Источник данных

Система закупок Самрук-Казына (zakup.sk.kz). Данные выгружены через MS-SQL → SQLite (eoz_full_auth.db), pipeline: intake → filter → prices → pool → report. Период: 2024–2026, только исполненные договоры (EXECUTED), исключены поставщики с признаками РНУ.

Классификация надёжности (IBCS SUCCESS)

  • Класс А (надёжно) — ≥30 позиций, спред цен <150%. Применима единая медиана.
  • Класс B (ограниченно) — ≥8 позиций. Медиана как ориентир.
  • Класс C (ненадёжно) — <8 позиций. Требуется спецификация или КП.

Обозначения на графиках (IBCS UNIFY)

  • ■ Фактические значения (медиана) — синий
  • ▨ Коридор P25–P75 — заливка
  • - - - Национальная медиана (референс) — пунктир
  • ▲ В рамках коридора · ◆ Вне коридора

Ограничения

  • Данные ограничены одним продуктом (бензин АИ-92). Для других ТРУ необходима замена ЕНС.
  • География поставок — только регионы, где есть исполненные контракты СКК.
  • РНУ-фильтр основан на реестре недобросовестных участников закупок СК.
